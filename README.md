### How I work

- **Design the system:** start from the problem and the platform's real limits, then choose the
  smallest architecture that solves it.
- **Build it for reuse:** components and tooling other developers can install, not one-off code.
- **Prove it works:** every automated check is shown failing on purpose before it's trusted, and every
  feature is verified on a real system.
